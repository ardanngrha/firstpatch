# FirstPatch

## Direction approved by the owner

The selected reference is the revised FirstPatch issue directory mockup, approved on 18 October 2026. Keep its ivory surface, forest-green actions, compact header, generous search toolbar, unified issue rows and inline contribution context. The owner approved the sans-serif revision after rejecting the original serif typography.

## Design Read

An approachable contribution directory for first-time open-source contributors. ENERGY 1 / RHYTHM 2 / MOTION 1. Search and issue selection are the focal interaction. Structured rows make comparison easy; an expanded detail panel interrupts the rhythm only when someone asks for context.

## Decisions

- Source Sans 3: humanist letterforms keep dense issue text legible and welcoming.
- Source Code Pro: reserved for repository identifiers and technical metadata.
- Ivory and forest green: retain the approved reference; green distinguishes actions and selected state.
- A stitched sprout mark: retain the approved first-party asset, representing a small contribution that grows.
- One unified list: users compare tasks, so a repeated reading axis beats isolated cards.
- Whitespace separates the search task from the results; rules separate related entries.
- Expand details in place: preserve search context while reading the contribution requirements.
- Source and checked time stay visible: an imported issue is a snapshot, not a live promise.
- Theme choice supports different reading environments; both themes use the same hierarchy and behavior.
- Motion is limited to state feedback, with reduced-motion support.

## Production adaptations

Replace sample content with real public GitHub data. Distinguish catalogue records from checked issues. Do not invent task difficulty, time estimates, summaries, star counts or source membership. A maintainer label is a signal, not a guarantee. Add native responsive reflow, accessible keyboard controls and pre-rendered content for SEO. Source directories and guides have their own accessible pages.
